# CarSky AWS live PoC — Terraform plan only

This directory is review-only in P3. No `terraform apply`, CloudFormation/CDK
deploy, ECR push, certificate creation or AWS resource mutation is authorized.
The current environment intentionally has no Terraform binary or AWS
credentials; only offline formatting/validation is permitted.

## Reviewed topology

- Region: `ap-southeast-1`, one always-warm `g4dn.xlarge` (T4 16 GiB).
- Two Kinesis Video Streams WebRTC `SINGLE_MASTER` signaling channels, road
  and cabin. They are signaling/P2P paths, not KVS recording streams.
- ECS EC2 launch type, `host` networking, one ASG with min=desired=max=1.
  The host sits in a public subnet and receives a public IPv4, so this design
  has outbound Internet access without NAT. It is not high availability even
  though the ASG may choose one of two AZ subnets.
- Direct ICE ingress is disabled by default. Supplying a reviewed, fixed
  sender CIDR opens UDP ephemeral ports only to that CIDR; otherwise TURN is
  expected. There is no SSH ingress and ECS Exec is disabled.
- One task owns both decoders and all temporal model state. It gets exactly one
  GPU, a read-only root filesystem and a task-local `/tmp` tmpfs.
- Decisions publish through AWS IoT Core MQTT-over-WSS with task-role SigV4,
  QoS 0, clean session and RETAIN=false (runtime contract). The task role can
  publish only the selected vehicle's decision subtree.
- Source and Android X.509 private keys are deliberately not generated by
  Terraform. Optional certificate ARNs bind externally enrolled identities;
  source receives temporary KVS-master credentials through one IoT role alias.

KVS WebRTC is not a generic WHIP endpoint. Before any apply, the source vendor
must prove the KVS signaling flow and exact H.264-frame/DataChannel metadata
mapping. A persistent same-host ingress adapter is required for WHIP/SRT-only
sources.

## Offline checks

After installing an approved Terraform version:

```bash
terraform -chdir=infra/aws-live fmt -check -recursive
terraform -chdir=infra/aws-live init -backend=false
terraform -chdir=infra/aws-live validate
```

Do not run `plan` against an account until a read-only planning session is
approved. Do not run `apply` until a later explicit provisioning approval.

| TURN, two tracks, 0–100% of 24/7 | $0–$15.55 |
| decisions, <=5 KiB, one subscriber | $0.86 (10 min/day), $41.47 (8 h/day), $124.42 (24/7) |
| CloudWatch/alarms/logs | remeasure from actual aggregate log volume |

The previously estimated complete range is about $553–$565 for 10 min/day,
$593–$610 for 8 h/day, or $676–$703 for 24/7. Before apply, recalculate using
the measured v2 envelope size and image size, CloudWatch logs/alarms/custom
metrics, Internet transfer, TURN path ratio, IoT subscribers, EBS snapshots,
ECR storage, public IPv4, tax/support, quota and actual regional capacity.

Singapore does not currently offer G5/G6. If the unchanged model/cadence fails
the T4 soak, the reviewed fallback is to move the whole stack—not split the
data plane—to `ap-southeast-5` on `g6.xlarge` (L4 24 GiB, compute estimate
$740.07/month). `g4dn.2xlarge` is not a GPU upgrade because it retains the same
T4 and VRAM.
